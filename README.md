# 📚 Online Book Store SQL Project

## 📌 Project Description
This project involves designing an **Online Book Store** database with three tables: `Books`, `Customers`, and `Orders`.  
It includes SQL queries to analyze customer behavior, book sales, and order trends.

## 📂 Project Files
- `1_Books.csv` → Contains book details.  
- `2_Customers.csv` → Customer information.  
- `3_Orders.csv` → Purchase records.  
- `4_Project_Questions.pdf` → The problem statements/questions.  
- `5_SQL_Project_Solutions.sql` → Contains all queries for analysis.  

## 🚀 Technologies Used
- **PostgreSQL**
- **SQL Queries** (Joins, Aggregations, Subqueries)
- **GitHub for version control**

## 📊 Key Insights & Queries Answered
✅ **Most frequently ordered book**  
✅ **Customers with highest spending**  
✅ **Monthly sales trend analysis**  
✅ **Total revenue generated by each book category**  
✅ **Number of books sold per month**
